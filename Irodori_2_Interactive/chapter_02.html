### **Grammar Point 6: 〜て/〜くて/〜で (Reason - Connecting sentences)**

Pehle chapter mein feelings ke saath て-form seekha. Ab aur detail:

#### **Formation:**

| Type | How to connect | Example |
|------|---------------|---------|
| Verb | て-form | いって、たべて、して |
| い-adj | い → くて | たかくて、おいしくて |
| な-adj | な-adj + で | しずかで、べんりで |
| Noun | Noun + で | あめで、びょうきで |

#### **Examples:**

**Verb て:**
```
でんしゃ が おくれて、ちこく しました。
(Densha ga okurete, chikoku shimashita.)
Train late thi, isliye late hua.
```

**い-adjective くて:**
```
この りょうり は からくて、たべられません。
(Kono ryouri wa karakute, taberaremasen.)
Yeh khana teekha hai, isliye kha nahi sakta.

しごと が いそがしくて、やすめません。
(Shigoto ga isogashikute, yasumemasen.)
Kaam busy hai, isliye aaram nahi mil raha.
```

**な-adjective で:**
```
この まち は しずかで、すき です。
(Kono machi wa shizuka de, suki desu.)
Yeh sheher shaant hai, isliye pasand hai.

かれ は しんせつで、にんき (人気) が あります。
(Kare wa shinsetsu de, ninki ga arimasu.)
Woh친절 hai, isliye popular hai.
```

**Noun で:**
```
あめで、でかけられませんでした。
(Ame de, dekakeraremasen deshita.)
Baarish ki wajah se, bahar nahi ja saka.

びょうきで、がっこう を やすみました。
(Byouki de, gakkou wo yasumimashita.)
Bimari ki wajah se, school chutti ki.
```

### **Grammar Point 7: 〜し、〜し (Multiple Reasons)**

**Plain form + し、Plain form + し = _____ bhi hai aur _____ bhi hai**

Multiple reasons dene ke liye - incomplete list (aur bhi reasons ho sakte hain):

#### **Examples:**

```
きょう は あたま が いたいし、ねつ も あるし、やすみたい。
(Kyou wa atama ga itai shi, netsu mo aru shi, yasumitai.)
Aaj sir dard bhi hai, bukhar bhi hai, aaram karna chahta hoon.

この レストラン は おいしいし、やすいし、よく いきます。
(Kono resutoran wa oishii shi, yasui shi, yoku ikimasu.)
Yeh restaurant tasty bhi hai, sasta bhi hai, aksar jaata hoon.

にほん は あんぜん (安全) だし、きれい だし、すき です。
(Nihon wa anzen da shi, kirei da shi, suki desu.)
Japan safe bhi hai, sundar bhi hai, pasand hai.

かれ は やさしいし、おもしろいし、あたま も いいし、すてき です。
(Kare wa yasashii shi, omoshiroi shi, atama mo ii shi, suteki desu.)
Woh accha bhi hai, funny bhi hai, smart bhi hai, kamaal hai.

この アパート は えき から ちかいし、やちん (家購) も やすいし、
きめました。
(Kono apaato wa eki kara chikai shi, yachin mo yasui shi, kimemashita.)
Yeh apartment station se paas bhi hai, kiraya bhi sasta hai, isliye decide kiya.
```

#### **Casual conversation mein:**

```
A: どうして にほん が すきなの？
(Doushite nihon ga suki nano?)
Kyun Japan pasand hai?

B: うーん、たべもの が おいしいし、ひと が やさしいし、
あんぜん だし... いろいろ あるよ。
(Uun, tabemono ga oishii shi, hito ga yasashii shi,
anzen da shi... iroiro aru yo.)
Hmm, khana tasty bhi hai, log acche bhi hain, safe bhi hai... bahut reasons hain.
```

### **Grammar Point 8: 〜すぎます (Too much / Bahut zyada)**

**Verb ます-stem + すぎます = Bahut zyada _____ karna**
**い-adj (い hatao) + すぎます = Bahut zyada _____**
**な-adj + すぎます = Bahut zyada _____**

#### **Examples:**

**Verb + すぎます:**
```
きのう、のみすぎました。あたま が いたい です。
(Kinou, nomisugimashita. Atama ga itai desu.)
Kal bahut zyada pee liya. Sir dard hai.

たべすぎて、おなか が いたい です。
(Tabesugite, onaka ga itai desu.)
Bahut zyada khaake, pet dard hai.

はたらきすぎて、つかれました。
(Hatarakisugite, tsukaremashita.)
Bahut zyada kaam karke, thak gaya.

ゲーム を しすぎて、めが つかれました。
(Geemu wo shisugite, me ga tsukaremashita.)
Bahut zyada game khelke, aankh thak gayi.
```

**Adjective + すぎます:**
```
この かばん は たかすぎます。
(Kono kaban wa takasugimasu.)
Yeh bag bahut mehenga hai.

この へや は せますぎます (狭い)。
(Kono heya wa semasugimasu.)
Yeh kamra bahut chhota hai.

この りょうり は からすぎます。
(Kono ryouri wa karasugimasu.)
Yeh khana bahut teekha hai.

ここ は しずかすぎて、ちょっと こわい です。
(Koko wa shizukasugite, chotto kowai desu.)
Yahaan bahut shaant hai, thoda darawna hai.
```

### **Grammar Point 9: 〜やすい / 〜にくい (Easy to / Hard to)**

**Verb ます-stem + やすい = _____ karna aasaan**
**Verb ます-stem + にくい = _____ karna mushkil**

#### **Examples:**

```
この ほん は よみやすい です。
(Kono hon wa yomiyasui desu.)
Yeh kitaab padhne mein aasaan hai.

この かんじ は おぼえにくい です。(覚える)
(Kono kanji wa oboeniukui desu.)
Yeh kanji yaad karna mushkil hai.

この くつ は あるきやすい です。
(Kono kutsu wa arukiyasui desu.)
Yeh joote chalne mein comfortable hain.

かのじょ は はなしやすい ひと です。
(Kanojo wa hanashiyasui hito desu.)
Woh baat karne mein aasaan/friendly insaan hai.
```

### **Grammar Point 10: 〜そう (Looks like / Lagta hai - Appearance)**

⚠️ Yeh **appearance/observation** ke basis pe opinion hai (hearsay wala そうです se alag!)

⚠️ **Exceptions:**
- いい → **よさそう** (NOT いそう)
- ない → **なさそう** (NOT ないそう)

#### **Examples:**

```
あめ が ふりそう です。
(Ame ga furisou desu.)
Baarish hone wali lagti hai.

この ケーキ は おいしそう です。
(Kono keeki wa oishisou desu.)
Yeh cake tasty lagta hai.

その しごと は たいへんそう ですね。
(Sono shigoto wa taihensou desu ne.)
Woh kaam mushkil lagta hai na.

かれ は げんきそう です。
(Kare wa genkisou desu.)
Woh healthy/energetic lagta hai.

あの ひと は しあわせそう ですね。
(Ano hito wa shiawasesou desu ne.)
Woh aadmi khush lagta hai na.
```

### **Grammar Point 11: 〜がる (Third person feelings/wants)**

⚠️ Japanese mein direct feelings (ほしい、〜たい、かなしい etc.) sirf **khud ke liye** use karte hain. **Dusron ke feelings** ke liye **〜がる** use hota hai.

**Formation:**
- い-adj (い hatao) + がる: さびしがる、うれしがる
- ほしい → ほしがる
- 〜たい → 〜たがる

#### **Examples:**

**Wrong:** ❌ かれ は さびしい です。 (He is lonely - direct)
**Correct:** ✓ かれ は さびしがって います。 (He seems/acts lonely)

```
こども は あたらしい おもちゃ を ほしがって います。
(Kodomo wa atarashii omocha wo hoshigatte imasu.)
Bachcha naya toy chahta hai (aisa lag raha hai).

いぬ は さんぽ に いきたがって います。
(Inu wa sanpo ni ikitagatte imasu.)
Kutta walk pe jaana chahta hai.

かのじょ は その ニュース を きいて、かなしがって いました。
(Kanojo wa sono nyuusu wo kiite, kanashigatte imashita.)
Woh news sunke dukhi lag rahi thi.

ともだち は にほん に いきたがって いますが、
おかね が ありません。
(Tomodachi wa nihon ni ikitagatte imasu ga, okane ga arimasen.)
Dost Japan jaana chahta hai (lagta hai), lekin paise nahi hain.
```

### **Expressing & Asking About Feelings:**

**Asking about feelings:**
```
どう したんですか？きぶん が わるそう ですね。
(Dou shitan desu ka? Kibun ga warusou desu ne.)
Kya hua? Tabiyat kharab lagti hai.

なに か あったんですか？
(Nanika attan desu ka?)
Kuch hua kya?

だいじょうぶ ですか？
(Daijoubu desu ka?)
Theek ho?

さいきん、どう？(最近)
(Saikin, dou?)
Aajkal kaisa hai?
```

**Expressing feelings:**
```
さいきん、ストレス が たまって います。
(Saikin, sutoresu ga tamatte imasu.)
Aajkal stress build up ho raha hai.

しごと が いそがしすぎて、ゆっくり やすめません。
(Shigoto ga isogashisugite, yukkuri yasumemasen.)
Kaam bahut busy hai, acche se aaram nahi mil raha.

なんだか さびしい きもち です。
(Nandaka sabishii kimochi desu.)
Kuch akela sa feel ho raha hai.

やっと おわって、ほっとしました。
(Yatto owatte, hotto shimashita.)
Finally khatam hua, sukoon mila.

ずっと これ を たのしみに して いました！
(Zutto kore wo tanoshimi ni shite imashita!)
Bahut der se iska intezaar kar raha tha!
```

**Showing empathy:**
```
それは たいへん でしたね。
(Sore wa taihen deshita ne.)
Woh mushkil tha na.

そんな こと あったんですか。つらかった でしょう。
(Sonna koto attan desu ka. Tsurakatta deshou.)
Aisa hua? Mushkil raha hoga.

わかります。わたし も おなじ けいけん が あります。
(Wakarimasu. Watashi mo onaji keiken ga arimasu.)
```
