### **Grammar Point 2: ～んです / ～のです (Explanation & Emphasis)**

**Plain form + んです = Actually _____ hai / Baat yeh hai ki _____**

Yeh tab use hota hai jab:
- Koi cheez explain kar rahe ho
- Reason bata rahe ho
- Background de rahe ho
- Emphasis kar rahe ho

#### **Formation:**

| Type | Pattern | Example |
|------|---------|---------|
| Verb | Plain + んです | いく**んです** |
| い-adj | い-adj + んです | たかい**んです** |
| な-adj | な-adj + **な** + んです | しずか**なんです** |
| Noun | Noun + **な** + んです | びょうき**なんです** |

#### **Examples:**

**Explaining situation:**
```
A: どうしたんですか？
(Doushitan desu ka?)
Kya hua? (What happened?)

B: あたま が いたいんです。
(Atama ga itain desu.)
Actually sir dard hai.
```

**Giving reason:**
```
A: きょう は やすみますか？
(Kyou wa yasumimasu ka?)
Aaj chutti loge?

B: はい、ねつ が あるんです。
(Hai, netsu ga arun desu.)
Haan, actually bukhar hai.
```

**Asking for explanation:**
```
どうして おくれたんですか？
(Doushite okuretan desu ka?)
Kyun late hue? (What's the reason?)

でんしゃ が とまったんです。
(Densha ga tomattan desu.)
Actually train ruk gayi thi.
```

#### **Casual form: ～んだ / ～の**

| Polite | Casual (male/neutral) | Casual (female/soft) |
|--------|----------------------|---------------------|
| いくんです | いくんだ | いくの |
| おいしいんです | おいしいんだ | おいしいの |
| びょうきなんです | びょうきなんだ | びょうきなの |

**Casual examples:**
```
A: どうしたの？ (Doushita no?) - Kya hua?
B: ちょっと つかれたんだ。(Chotto tsukaretan da.) - Thoda thak gaya.
```

### **Grammar Point 4: ～たら (If/When - Conditional)**

**た form + ら = Agar _____ ho toh / Jab _____ ho tab**

#### **Formation:**
- Verb た form + ら: いった**ら**、たべた**ら**、した**ら**
- い-adj かった + ら: たかかった**ら**、よかった**ら**
- な-adj だった + ら: しずかだった**ら**
- Noun だった + ら: あめだった**ら**

#### **Uses:**

**1. Conditional (If):**
```
あした あめ が ふったら、うち に います。
(Ashita ame ga futtara, uchi ni imasu.)
Kal baarish hui toh, ghar pe rahunga.

やすかったら、かいます。
(Yasukattara, kaimasu.)
Sasta hua toh, khareedunga.

ひまだったら、あそびに きて ください。
(Hima dattara, asobi ni kite kudasai.)
Free ho toh, ghumne aao.
```

**2. When (time):**
```
うち に かえったら、でんわ します。
(Uchi ni kaettara, denwa shimasu.)
Ghar pahunchke, phone karunga.

しごと が おわったら、のみに いきましょう。
(Shigoto ga owattara, nomi ni ikimashou.)
Kaam khatam hone pe, peene chalte hain.
```

**3. Discovery (When I did, I found):**
```
まど を あけたら、とり が いました。
(Mado wo aketara, tori ga imashita.)
Khidki kholi toh, chidiya thi.

かばん を あけたら、さいふ が なかった。
(Kaban wo aketara, saifu ga nakatta.)
Bag khola toh, wallet nahi thi.
```

### **Grammar Point 5: ～ても (Even if / _____ ke baawajood)**

**て-form + も = _____ ke baawajood bhi / Chahe _____ ho**

#### **Formation:**
- Verb て form + も: いって**も**、たべて**も**
- い-adj くて + も: たかくて**も**
- な-adj で + も: しずかで**も**
- Noun で + も: あめで**も**

#### **Examples:**
```
あめ が ふっても、いきます。
(Ame ga futtemo, ikimasu.)
Baarish ho ke bhi, jaunga.

たかくても、ほしい です。
(Takakutemo, hoshii desu.)
Mehenga ho ke bhi, chahiye.

いそがしくても、れんしゅう します。
(Isogashikutemo, renshuu shimasu.)
Busy ho ke bhi, practice karunga.

にちようびでも、しごと が あります。
(Nichiyoubi demo, shigoto ga arimasu.)
Sunday ho ke bhi, kaam hai.

なんかい よんでも、わかりません。
(Nankai yondemo, wakarimasen.)
Kitni baar bhi padho, samajh nahi aata.
```

### **Conversation Practice:**

```
A: きのう、すごい こと が あったんだ。
(Kinou, sugoi koto ga attan da.)
Kal bahut amazing cheez hui.

B: えー、なに なに？
(Ee, nani nani?)
Kya kya? Bata!

A: えき で ゆうめいな サッカーせんしゅ (選手) に あったんだ！
(Eki de yuumei na sakkaa senshu ni attan da!)
Station pe famous football player se mila!

B: うそ！まじで？
(Uso! Maji de?)
Jhooth! Seriously?

A: ほんと ほんと。いっしょに しゃしん も とったんだ。
(Honto honto. Issho ni shashin mo tottan da.)
Sach sach. Saath mein photo bhi liya.

B: すごーい！いいなー！みせて みせて！
(Sugooi! Ii naa! Misete misete!)
Amazing! Lucky! Dikha dikha!

A: はい、これ。
(Hai, kore.)
Haan, yeh dekh.

B: わー、ほんとう だ！どきどき したでしょ？
(Waa, hontou da! Dokidoki shita desho?)
Wow, sach mein hai! Nervous hua hoga na?

A: うん、すごく きんちょう (緊張) した。でも、やさしい ひと だったよ。
(Un, sugoku kinchou shita. Demo, yasashii hito datta yo.)
Haan, bahut nervous hua. Lekin, accha aadmi tha.

B: よかったね！
(Yokatta ne!)
Accha hua!
```

#### **Examples:**

**Verb + すぎます:**

#### **Examples:**

```
この ほん は よみやすい です。
(Kono hon wa yomiyasui desu.)
Yeh kitaab padhne mein aasaan hai.

(Kono kanji wa oboeniukui desu.)
Yeh kanji yaad karna mushkil hai.

この くつ は あるきやすい です。
(Kono kutsu wa arukiyasui desu.)
Yeh joote chalne mein comfortable hain.

この スマホ は つかいやすい です。
(Kono sumaho wa tsukaiyasui desu.)
Yeh phone use karna aasaan hai.

せんせい の せつめい は わかりやすい です。

この みち は せまくて、くるま で とおりにくい です。(通る)
(Kono michi wa semakute, kuruma de tooriniukui desu.)

```

### **Grammar Point 10: ～そう (Looks like / Lagta hai - Appearance)**

**Verb ます-stem + そう = _____ hone wala hai**
**い-adj (い hatao) + そう = _____ lagta hai**
**な-adj + そう = _____ lagta hai**

⚠️ Yeh **appearance/observation** ke basis pe opinion hai (hearsay wala そうです se alag!)

#### **Formation:**

| Type | Original | ～そう form |
|------|----------|-----------|
| Verb | ふります | ふり**そう** |
| Verb | おちます (落ちる) | おち**そう** |
| い-adj | おいしい | おいし**そう** |
| い-adj | たかい | たか**そう** |
| な-adj | げんき | げんき**そう** |
| な-adj | たいへん | たいへん**そう** |

⚠️ **Exceptions:**
- いい → **よさそう** (NOT いそう)
- ない → **なさそう** (NOT ないそう)

#### **Examples:**

**Verb + そう (about to happen):**
```
あめ が ふりそう です。
(Ame ga furisou desu.)
Baarish hone wali lagti hai.

この はし (橋) は こわれそう です。(壊れる)
(Kono hashi wa kowaresou desu.)
Yeh pul tootne wala lagta hai.

おなか が すいて、たおれそう です。(倒れる)
(Onaka ga suite, taoresou desu.)
Bhook lagi hai, girne wala hoon.
```

**Adjective + そう (looks like):**
```
この ケーキ は おいしそう です。
(Kono keeki wa oishisou desu.)
Yeh cake tasty lagta hai.

その しごと は たいへんそう ですね。
(Sono shigoto wa taihensou desu ne.)
Woh kaam mushkil lagta hai na.

かれ は げんきそう です。
(Kare wa genkisou desu.)
Woh healthy/energetic lagta hai.

この もんだい は かんたんそう です。(簡単)
(Kono mondai wa kantansou desu.)
Yeh problem aasaan lagti hai.

あの ひと は しあわせそう ですね。
(Ano hito wa shiawasesou desu ne.)
Woh aadmi khush lagta hai na.

このりょうり、からそう... だいじょうぶかな。
(Kono ryouri, karasou... daijoubu kana.)
Yeh khana teekha lagta hai... theek hoga kya.
```

**Negative + そう:**
```
きょう は あめ が ふらなさそう です。
(Kyou wa ame ga furanasasou desu.)
Aaj baarish nahi lagti.

このレストラン、あまり おいしくなさそう...
(Kono resutoran, amari oishikunasasou...)
Yeh restaurant zyada tasty nahi lagta...

かれ は げんきじゃなさそう ですね。
(Kare wa genkijanasasou desu ne.)
Woh theek nahi lagta na.
```

### **Grammar Point 11: ～がる (Third person feelings/wants)**

⚠️ Japanese mein direct feelings (ほしい、～たい、かなしい etc.) sirf **khud ke liye** use karte hain. **Dusron ke feelings** ke liye **～がる** use hota hai.

**Formation:**
- い-adj (い hatao) + がる: さびし**がる**、うれし**がる**
- ほしい → ほし**がる**
- ～たい → ～た**がる**

#### **Examples:**

**Wrong:** ❌ かれ は さびしい です。 (He is lonely - direct)
**Correct:** ✓ かれ は さびし**がって** います。 (He seems/acts lonely)

```
こども は あたらしい おもちゃ を ほしがって います。
(Kodomo wa atarashii omocha wo hoshigatte imasu.)
Bachcha naya toy chahta hai (aisa lag raha hai).

いぬ は さんぽ に いきたがって います。
(Inu wa sanpo ni ikitagatte imasu.)
Kutta walk pe jaana chahta hai.

かのじょ は その ニュース を きいて、かなしがって いました。
(Kanojo wa sono nyuusu wo kiite, kanashigatte imashita.)
Woh news sunke dukhi lag rahi thi.

ともだち は にほん に いきたがって いますが、
おかね が ありません。
(Tomodachi wa nihon ni ikitagatte imasu ga, okane ga arimasen.)
Dost Japan jaana chahta hai (lagta hai), lekin paise nahi hain.
```

**Asking about feelings:**

**Showing empathy:**

```
むり しないで くださいね。
(Muri shinaide kudasai ne.)
Zyada strain mat lo.
```

### **Grammar Point 14: ～と おなじ / ～と ちがう (Same as / Different from)**

**A と B は おなじ = A aur B same hain**

#### **Examples:**

```

(Kono kaban to sono kaban wa onaji iro desu ne.)
Yeh bag aur woh bag same color hain na.

わたし の いけん (意見) は あなた と おなじ です。
(Watashi no iken wa anata to onaji desu.)
Meri opinion aapki jaisi hai.

```

### **Grammar Point 15: ～のように / ～みたいに (Like _____ / _____ jaisa)**

**Noun + のように / みたいに = _____ ki tarah / _____ jaisa**

⚠️ **みたいに** is more casual than **のように**

#### **Examples:**

```

(Yuki no you ni shiroi hana desu.)
```

**"Like this/that":**
```

```

### **Grammar Point 17: ～そうです (Hearsay / Suna hai ki)**

⚠️ Yeh pehle wale appearance そう se ALAG hai!

**Plain form + そうです = _____ suna hai / According to _____**

#### **Formation:**

| Type | Pattern | Example |
|------|---------|---------|
| Verb | Plain + そうです | いく**そうです** |
| い-adj | い-adj + そうです | たかい**そうです** |
| な-adj | な-adj + **だ** + そうです | しずか**だそうです** |
| Noun | Noun + **だ** + そうです | あめ**だそうです** |

#### **Examples:**

```
あした は あめ が ふる そうです。
(Ashita wa ame ga furu sou desu.)
Kal baarish hogi suna hai.

あの レストラン は おいしい そうです。
(Ano resutoran wa oishii sou desu.)
Woh restaurant tasty hai suna hai.

かれ は らいげつ けっこんする そうです。
(Kare wa raigetsu kekkon suru sou desu.)
Woh agle mahine shaadi karega suna hai.

にほん の ふゆ は さむい そうです。
(Nihon no fuyu wa samui sou desu.)
Japan ki sardi thandi hoti hai suna hai.

ニュース によると、あした ゆき が ふる そうです。
(Nyuusu ni yoru to, ashita yuki ga furu sou desu.)
News ke mutabiq, kal barf giregi.
```

#### **Difference: Appearance そう vs Hearsay そう:**

| Type | Formation | Meaning | Example |
|------|-----------|---------|---------|
| **Appearance** | Adj-stem + そう | Lagta hai (dekhke) | おいし**そう** (Tasty lagta hai) |
| **Hearsay** | Plain + そうです | Suna hai | おいしい**そうです** (Tasty hai suna hai) |

```
この ケーキ は おいしそう です。 (looks delicious - dekhke)
この ケーキ は おいしい そうです。 (I heard it's delicious - sunke)
```

### **Grammar Point 18: ～らしい (Seems like / Apparently)**

```
その えいが は おもしろい らしい ですよ。
(Sono eiga wa omoshiroi rashii desu yo.)

```

### **Comparing Cultures - Example:**

```
にほん と インド の ぶんか を くらべると、

(Nihon to Indo no bunka wo kuraberu to,

(Demo, tabekata wa chigaimasu.

Lekin, khaane ka tareeka alag hai.

にほん の おしょうがつ は インド の ディワリ に
にている と おもいます。
```

### **Grammar Point 19: ～てから (After doing / _____ karne ke baad)**

**て-form + から = _____ karne ke baad**

#### **Examples:**

```
て を あらってから、りょうり を します。
(Te wo aratte kara, ryouri wo shimasu.)
Haath dhone ke baad, khana banata hoon.

やさい を きってから、いためます。
(Yasai wo kitte kara, itamemasu.)
Sabzi kaatne ke baad, stir-fry karta hoon.

ごはん を たべてから、でかけましょう。
(Gohan wo tabete kara, dekakemashou.)
Khana khaane ke baad, bahar chalte hain.

にほん に きてから、すし が すきに なりました。
(Nihon ni kite kara, sushi ga suki ni narimashita.)
Japan aane ke baad, sushi pasand ho gayi.

しごと が おわってから、ジム に いきます。
(Shigoto ga owatte kara, jimu ni ikimasu.)
Kaam khatam hone ke baad, gym jaata hoon.
```

#### **Difference: ～てから vs ～たあと:**

Both mean "after doing" but slight nuance:
- **～てから**: Emphasizes sequence (pehle yeh, phir woh)
- **～たあと**: Just states "after" (time reference)

```
ごはん を たべてから、すぐ でかけます。
(Sequence emphasis - khana khaake, turant nikalta hoon)

ごはん を たべたあと、テレビ を みます。
(Time reference - khane ke baad TV dekhta hoon)
```

### **Grammar Point 26: ～あいだ / ～あいだに (During / While)**

**Duration/Activity + あいだ = _____ ke dauraan (continuous)**
**Duration/Activity + あいだに = _____ ke dauraan mein (point in time)**

#### **Difference:**

- **あいだ**: Poore time mein continuously
- **あいだに**: Us time period ke andar kisi point pe

#### **Examples:**

**あいだ (continuous):**
```

(Natsuyasumi no aida, zutto uchi ni imashita.)

(Kaigi no aida, memo wo torimasu.)

ね て いる あいだ、ゆめ を みました。
(Nete iru aida, yume wo mimashita.)
Sote waqt, sapna dekha.
```

**あいだに (point in time):**
```
なつやすみ の あいだに、りょこう に いきました。
(Natsuyasumi no aida ni, ryokou ni ikimashita.)
Summer vacation ke dauraan mein, travel gaya.

ひるやすみ の あいだに、ぎんこう に いきたい です。
(Hiruyasumi no aida ni, ginkou ni ikitai desu.)
Lunch break ke dauraan mein, bank jaana chahta hoon.

でんしゃ を まって いる あいだに、ほん を よみました。
(Densha wo matte iru aida ni, hon wo yomimashita.)
Train wait karte waqt, kitaab padhi.

わかい あいだに、いろいろな けいけん を した ほうが いいです。
(Wakai aida ni, iroirona keiken wo shita hou ga ii desu.)
Jawaan hote waqt, bahut experiences karne chahiye.
```

### **Grammar Point 28: ～ところ (Just about to / Just did / In the middle of)**

**Verb forms + ところ = _____ hi / _____ wala hai / _____ ke beech mein**

Yeh action ka **exact point** batata hai:

| Pattern | Meaning | Example |
|---------|---------|---------|
| Dictionary + ところ | About to do | いま、でかける**ところ**です (Abhi nikalne wala hoon) |
| ている + ところ | In the middle of | いま、たべている**ところ**です (Abhi kha raha hoon) |
| た + ところ | Just did | いま、かえってきた**ところ**です (Abhi hi wapas aaya) |

#### **Examples:**

**Dictionary form + ところ (about to):**
```
A: いま、いそがしい？
   (Ima, isogashii?)

B: うん、いま でかける ところ なんだ。あとで いい？
   (Un, ima dekakeru tokoro nan da. Ato de ii?)

```

```

```

```
Abhi hi wapas aaya.

さっき、ごはん を たべた ところ です。
(Sakki, gohan wo tabeta tokoro desu.)
Abhi hi khana khaya.

ちょうど あなた の こと を かんがえていた ところ です。
(Choudo anata no koto wo kangaete ita tokoro desu.)
Bilkul tumhare baare mein soch raha tha.
```

### **Grammar Point 34: ～てある (Has been done / State of completion)**

**Transitive verb て-form + ある = _____ kiya hua hai (kisi ne)**

Koi action ka result abhi bhi hai - state batata hai:

#### **Examples:**

```
まど が あけて あります。
(Mado ga akete arimasu.)
Khidki khuli hui hai. (kisi ne kholi)

でんき が けして あります。
(Denki ga keshite arimasu.)
Light band ki hui hai.

つくえ の うえ に メモ が かいて あります。
(Tsukue no ue ni memo ga kaite arimasu.)
Table pe note likha hua hai.

れいぞうこ に ビール が ひやして あります。
(Reizouko ni biiru ga hiyashite arimasu.)
Fridge mein beer thanda kiya hua hai.

へや は もう そうじして あります。
(Heya wa mou soujishite arimasu.)
Room already saaf kiya hua hai.

ひっこし の ために、にもつ が つめて あります。(詰める)
(Hikkoshi no tame ni, nimotsu ga tsumete arimasu.)
Shifting ke liye, saamaan pack kiya hua hai.
```

#### **Difference: ている vs てある:**

| Pattern | Meaning | Example |
|---------|---------|---------|
| ている | Action happening / State (natural) | まど が あいて**いる** (Khidki khuli hai - state) |
| てある | Action done by someone (result) | まど が あけて**ある** (Kisi ne kholi hai) |

⚠️ **てある** sirf transitive verbs ke saath use hota hai!

## 3) Grammar Point 36: ～そうです  
## Meaning: “Suna hai ki…”

### Pattern:
- Verb plain form + そうです
- い-adjective + そうです
- な-adjective + だそうです
- Noun + だそうです

### Examples:
- あした は あめ が ふる **そうです**。  
  → Kal baarish hogi **suna hai**.

  → Yeh event free hai **suna hai**.

- らいしゅう、えき の ちかく で おまつり が ある **そうです**。  
  → Agle hafte station ke paas festival hai **suna hai**.

## 3) Grammar Point 45: ～てあげます / ～てもらいます / ～てくれます

Ye Japanese ka bahut important favour pattern hai.

---

### A) ～てあげます  
## Meaning: “Main kisi ke liye kar deta hoon”

**[Main] + [person] に + てあげます**

#### Examples:
- ともだち に にほんご を おしえて **あげました**。  
  → Maine dost ko Japanese sikhaya.

- こども に ほん を よんで **あげます**。  
  → Main bacche ko book padhkar sunata hoon.

- おばあさん に にもつ を もって **あげました**。  
  → Maine budhiya ke liye saamaan uthaya.

---

### B) ～てもらいます  
## Meaning: “Mere liye kisi ne kiya”

**[Main] は [person] に + てもらいます**

#### Examples:
- ともだち に くるま で えき まで おくって **もらいました**。  
  → Dost ne mujhe car se station tak chhoda.

- せんせい に さくぶん (作文) を みて **もらいました**。  
  → Teacher ne mera essay check kiya.

- かいしゃ の ひと に てつづき を てつだって **もらいました**。  
  → Company ke aadmi ne procedure mein madad ki.

---

### C) ～てくれます  
## Meaning: “Kisi ne mere liye kiya”

**[Person] が [main/mere group] に + てくれます**

#### Examples:
- ともだち が しゅくだい を てつだって **くれました**。  
  → Dost ne mera homework mein help ki.

- きんじょ の ひと が みち を おしえて **くれました**。  
  → Pados ke aadmi ne rasta bataya.

- かのじょ が おべんとう を つくって **くれました**。  
  → Usne mere liye lunch box banaya.

---

### Quick difference:
- **あげる** = main deta hoon / main karta hoon
- **もらう** = mujhe mila
- **くれる** = kisi ne mujhe diya / mere liye kiya

---

## 4) Grammar Point 46: ～てくれませんか

## 5) Grammar Point 91: ～ように なって きました  
## Meaning: “Dheere dheere ... hone laga”

**Dictionary / potential form + ように なって きました**

### Examples:
- にほんご が だんだん わかる **ように なって きました**。  
  → Dheere dheere Japanese samajh aane lagi.

- ひとりで てつづき が できる **ように なって きました**。  
  → Dheere dheere khud se procedures karne laga.

- にほん の せいかつ に なれる **ように なって きました**。  
  → Dheere dheere Japan ki life ki aadat padne lagi.

- じぶん の いけん を にほんごで いえる **ように なって きました**。  
  → Main dheere dheere Japanese mein apni opinion bolne laga.

---

## 6) Grammar Point 92: ～ように なりたいです  
## Meaning: “Main ... karne layak hona chahta hoon / want to become able to”

**Dictionary / potential form + ように なりたいです**

### Examples:
- もっと じょうず に はなせる **ように なりたいです**。  
  → Main aur acchi Japanese bol paana chahta hoon.

- けいご が つかえる **ように なりたいです**。  
  → Main keigo use kar paana chahta hoon.

- しんぶん (新聞) が よめる **ように なりたいです**。  
  → Main newspaper padh paana chahta hoon.

- にほんじん と しぜんに はなせる **ように なりたいです**。  
  → Main Japanese logon se naturally baat kar paana chahta hoon.

## 7) Grammar Point 93: ～て くれて / ～て いただいて うれしかったです  
## Meaning: “... karne se mujhe khushi hui”

### Examples:
- ともだち が てつだって **くれて うれしかったです**。  
  → Dost ne help ki, mujhe bahut khushi hui.

- せんせい が しんせつに おしえて **くださって うれしかったです**。  
  → Teacher ne pyar se sikhaya, mujhe accha laga.

- みなさん に たすけて **いただいて うれしかったです**。  
  → Sab ne help ki, mujhe bahut khushi hui.

- にほんじん の ともだち が できて、ほんとう に うれしかったです。  
  → Japanese dost bane, mujhe sach mein bahut khushi hui.

## 8) Talking about your progress

### Sample paragraph:
```
にほん に きた ばかり の ころ は、
ことば も せいかつ も ぜんぜん わかりませんでした。
(Nihon ni kita bakari no koro wa,
kotoba mo seikatsu mo zenzen wakarimasen deshita.)
Jab main naya naya Japan aaya tha,
na language samajhta tha na life.

でも、まいにち すこしずつ べんきょうして、
いまは にほんご で かんたんな かいわ が できる
ように なって きました。
(Demo, mainichi sukoshizutsu benkyou shite,
ima wa nihongo de kantan na kaiwa ga dekiru
you ni natte kimashita.)
Lekin, har roz thoda thoda padhkar,
ab Japanese mein simple conversation karne laga hoon.

まだ かんじ は にがてですが、
これからも べんきょうを つづけたいです。
(Mada kanji wa nigate desu ga,
korekara mo benkyou wo tsuzuketai desu.)
Abhi bhi kanji weak point hai,
lekin aage bhi padhai continue karna chahta hoon.

にほんご を べんきょうして よかった と おもっています。
(Nihongo wo benkyou shite yokatta to omotte imasu.)
Mujhe lagta hai Japanese padhkar accha hua.
```

## 10) Looking ahead - future goals

### Example:
```
これからは、もっと にほんご の ごい (語彙) を ふやして、

(Korekara mo akiramenaide, benkyou wo tsuzukemasu.)
Aage bhi give up kiye bina padhai continue karunga.
```
