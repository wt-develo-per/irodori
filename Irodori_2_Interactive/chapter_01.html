きょう は たいへんな いちにち でした。
🚆 あさ、電車（でんしゃ）が 止（と）まったんです。
⏰ だから、会社（かいしゃ）に 遅（おく）れて しまいました。

Hindi Translation: Aaj bahut mushkil din tha. Subah actually train ruk gayi thi (densha ga tomarkan desu). Isliye office late pahunch gaya. Lekin boss acche the toh sukoon mila (hotto shimashita).
Explanation & EmphasisPt 2
Plain Form + んです / のです / んだ

Use ～んです (polite) or ～んだ / ～の (casual) to explain a reason, provide background context, or emphasize "Actually... / Baat yeh hai ki...":
• 頭（あたま）が 痛（いた）いんです。 (Actually my head hurts).
• 熱（ねつ）が あるんです。 (Baat ye hai ki bukhar hai).
• 電車（でんしゃ）が 止（と）まったんです。 (Actually the train stopped).
• Note: For な-adj and Nouns, add な before んです (e.g., 病気（びょうき）なんです - Actually sick).

Reason for FeelingPt 3
Verb て-form + Emotion Word

Use Verb て-form before an emotion adjective to state "Because of doing X, I feel Y":
• 試験（しけん）に 受（う）かって、嬉（うれ）しいです。 (Passed exam, so I'm happy / Exam pass karke khush hoon).
• 友達（ともだち）が 帰（かえ）って、寂（さび）しいです。 (Friend went home, so I feel lonely).
• 財布（さいふ）を なくして、びっくりしました。 (Lost wallet, so I was shocked).

⚖️ Interactive Plain Form & Conditional Conjugator (Lines 61–96, 198–280)

Convert polite speech into Plain Forms (essential for casual chat and ～んです), condition ～たら (If/When), and concession ～ても (Even if/Despite)!

Condition / When / DiscoveryPt 4
た-form + ら (If / When / Found)

Add ら to any past tense Plain Form (た-form) to express 3 vital functions:
• 1. Conditional (If): 明日（あした）雨（あめ）が 降（ふ）ったら、家（うち）に い ます。 (If it rains tomorrow, I'll stay home / Baarish hui toh ghar pe rahunga).
• 2. When (Time sequence): 家（うち）に 帰（かえ）ったら、電話（でんわ）します。 (When I get home, I'll call you).
• 3. Discovery (When I did X, found Y): 窓（まど）を 開（あ）けたら、鳥（とり）が い ました。 (When I opened the window, there was a bird!).

Concession / DespitePt 5
て-form + も (Even if / Despite)

Add も after any て-form / で to express "Even if X happens / Despite X":
• 雨（あめ）が 降（ふ）っても、行（い）きます。 (Even if it rains, I will go / Baarish ho ke bhi jaunga).
• 高（たか）くても、ほしいです。 (Even if it's expensive, I want it).
• 忙（いそが）しくても、練習（れんしゅう）します。 (Even if busy, I will practice).
• 日曜日（にちようび）でも、仕事（しごと）が あります。 (Even on Sunday, I have work).

### **Grammar Point 2: ～んです / ～のです (Explanation & Emphasis)**

**Plain form + んです = Actually _____ hai / Baat yeh hai ki _____**

Yeh tab use hota hai jab:
- Koi cheez explain kar rahe ho
- Reason bata rahe ho
- Background de rahe ho
- Emphasis kar rahe ho

#### **Formation:**

| Type | Pattern | Example |
|------|---------|---------|
| Verb | Plain + んです | いく**んです** |
| い-adj | い-adj + んです | たかい**んです** |
| な-adj | な-adj + **な** + んです | しずか**なんです** |
| Noun | Noun + **な** + んです | びょうき**なんです** |

#### **Examples:**

**Explaining situation:**
```
A: どうしたんですか？
(Doushitan desu ka?)
Kya hua? (What happened?)

B: あたま が いたいんです。
(Atama ga itain desu.)
Actually sir dard hai.
```

**Giving reason:**
```
A: きょう は やすみますか？
(Kyou wa yasumimasu ka?)
Aaj chutti loge?

B: はい、ねつ が あるんです。
(Hai, netsu ga arun desu.)
Haan, actually bukhar hai.
```

**Asking for explanation:**
```
どうして おくれたんですか？
(Doushite okuretan desu ka?)
Kyun late hue? (What's the reason?)

でんしゃ が とまったんです。
(Densha ga tomattan desu.)
Actually train ruk gayi thi.
```

#### **Casual form: ～んだ / ～の**

| Polite | Casual (male/neutral) | Casual (female/soft) |
|--------|----------------------|---------------------|
| いくんです | いくんだ | いくの |
| おいしいんです | おいしいんだ | おいしいの |
| びょうきなんです | びょうきなんだ | びょうきなの |

**Casual examples:**
```
A: どうしたの？ (Doushita no?) - Kya hua?
B: ちょっと つかれたんだ。(Chotto tsukaretan da.) - Thoda thak gaya.
```

### **Grammar Point 4: ～たら (If/When - Conditional)**

**た form + ら = Agar _____ ho toh / Jab _____ ho tab**

#### **Formation:**
- Verb た form + ら: いった**ら**、たべた**ら**、した**ら**
- い-adj かった + ら: たかかった**ら**、よかった**ら**
- な-adj だった + ら: しずかだった**ら**
- Noun だった + ら: あめだった**ら**

#### **Uses:**

**1. Conditional (If):**
```
あした あめ が ふったら、うち に います。
(Ashita ame ga futtara, uchi ni imasu.)
Kal baarish hui toh, ghar pe rahunga.

やすかったら、かいます。
(Yasukattara, kaimasu.)
Sasta hua toh, khareedunga.

ひまだったら、あそびに きて ください。
(Hima dattara, asobi ni kite kudasai.)
Free ho toh, ghumne aao.
```

**2. When (time):**
```
うち に かえったら、でんわ します。
(Uchi ni kaettara, denwa shimasu.)
Ghar pahunchke, phone karunga.

しごと が おわったら、のみに いきましょう。
(Shigoto ga owattara, nomi ni ikimashou.)
Kaam khatam hone pe, peene chalte hain.
```

**3. Discovery (When I did, I found):**
```
まど を あけたら、とり が いました。
(Mado wo aketara, tori ga imashita.)
Khidki kholi toh, chidiya thi.

かばん を あけたら、さいふ が なかった。
(Kaban wo aketara, saifu ga nakatta.)
Bag khola toh, wallet nahi thi.
```

### **Grammar Point 5: ～ても (Even if / _____ ke baawajood)**

**て-form + も = _____ ke baawajood bhi / Chahe _____ ho**

#### **Formation:**
- Verb て form + も: いって**も**、たべて**も**
- い-adj くて + も: たかくて**も**
- な-adj で + も: しずかで**も**
- Noun で + も: あめで**も**

#### **Examples:**
```
あめ が ふっても、いきます。
(Ame ga futtemo, ikimasu.)
Baarish ho ke bhi, jaunga.

たかくても、ほしい です。
(Takakutemo, hoshii desu.)
Mehenga ho ke bhi, chahiye.

いそがしくても、れんしゅう します。
(Isogashikutemo, renshuu shimasu.)
Busy ho ke bhi, practice karunga.

にちようびでも、しごと が あります。
(Nichiyoubi demo, shigoto ga arimasu.)
Sunday ho ke bhi, kaam hai.

なんかい よんでも、わかりません。
(Nankai yondemo, wakarimasen.)
Kitni baar bhi padho, samajh nahi aata.
```

### **Talking About Your Day:**

**Pattern: Today's events + Feelings**

```
きょう は たいへんな いちにち でした。
(Kyou wa taihen na ichinichi deshita.)
Aaj bahut mushkil din tha.

あさ、でんしゃ が おくれて、かいしゃ に おくれて しまいました。
(Asa, densha ga okurete, kaisha ni okurete shimaimashita.)
Subah train late thi, office late pahunch gaya.

それから、だいじな かいぎ が あったんですが、
しりょう (資料) を わすれて しまって、こまりました。
(Sorekara, daiji na kaigi ga attan desu ga,
shiryou wo wasurete shimatte, komarimashita.)
Phir, important meeting thi, lekin
documents bhool gaya, bahut pareshan hua.

でも、ぶちょう が やさしくて、だいじょうぶ でした。
(Demo, buchou ga yasashikute, daijoubu deshita.)
Lekin, boss acche the, toh theek ho gaya.

ほっとしました。
(Hotto shimashita.)
Sukoon mila.

つかれましたが、いい けいけん でした。
(Tsukaremashita ga, ii keiken deshita.)
Thak gaya, lekin accha experience tha.
```

### **Reacting to News/Stories:**

| Japanese | Reading | Meaning | When to use |
|----------|---------|---------|-------------|
| えー！ | Ee! | What! | Surprise |
| うそ！/ うそー！ | Uso! | No way!/Jhooth! | Disbelief |
| まじ？/ まじで？ | Maji? / Maji de? | Seriously? | Casual surprise |
| ほんとう？/ ほんと？ | Hontou? / Honto? | Really? | Asking confirmation |
| すごい！/ すごーい！ | Sugoi! | Amazing! | Impressed |
| やばい！ | Yabai! | Wow!/Oh no! | Strong reaction (+/-) |
| かわいそう (可哀想) | Kawaisou | Poor thing | Sympathy |

### **Conversation Practice:**

```
A: きのう、すごい こと が あったんだ。
(Kinou, sugoi koto ga attan da.)
Kal bahut amazing cheez hui.

B: えー、なに なに？
(Ee, nani nani?)
Kya kya? Bata!

A: えき で ゆうめいな サッカーせんしゅ (選手) に あったんだ！
(Eki de yuumei na sakkaa senshu ni attan da!)
Station pe famous football player se mila!

B: うそ！まじで？
(Uso! Maji de?)
Jhooth! Seriously?

A: ほんと ほんと。いっしょに しゃしん も とったんだ。
(Honto honto. Issho ni shashin mo tottan da.)
Sach sach. Saath mein photo bhi liya.

B: すごーい！いいなー！みせて みせて！
(Sugooi! Ii naa! Misete misete!)
Amazing! Lucky! Dikha dikha!

A: はい、これ。
(Hai, kore.)
Haan, yeh dekh.

B: わー、ほんとう だ！どきどき したでしょ？
(Waa, hontou da! Dokidoki shita desho?)
Wow, sach mein hai! Nervous hua hoga na?

A: うん、すごく きんちょう (緊張) した。でも、やさしい ひと だったよ。
(Un, sugoku kinchou shita. Demo, yasashii hito datta yo.)
Haan, bahut nervous hua. Lekin, accha aadmi tha.

B: よかったね！
(Yokatta ne!)
Accha hua!
```
