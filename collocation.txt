# 🔥 Memorize These 15 First

These alone appear constantly in daily Japanese:

1. きをつける → dhyan rakhna
2. きになる → curiosity hona
3. しゃしんをとる → photo lena
4. でんわをかける → phone karna
5. れんらくをする → contact karna
6. べんきょうする → padhai karna
7. しごとをする → kaam karna
8. じかんがかかる → time lagna
9. おかねをつかう → paise kharch karna
10. りょこうする → travel karna
11. よやくする → booking karna
12. すきになる → pasand aane lagna
13. げんきになる → energetic ho jana
14. まにあう → time par pahunchna
15. がんばる → mehnat karna / best dena

### Pro tip

When memorizing, learn them as **one unit**, not separate words:

* ❌ しゃしん = photo + とる = take

* ✅ しゃしんをとる = "photo lena"

* ❌ でんわ = phone + かける = hang/apply

* ✅ でんわをかける = "phone karna"

This chunk-based learning is much closer to how native speakers actually use Japanese.
