Desire & Invitations: ～たい / ～きましょう / ～ませんか ます Stem Transformations
Verb ます Stem + たい です (Want to) / ましょう (Let's) / ませんか (Won't you?)

To express what you want to do or to invite friends, simply remove ます from the verb and attach the target ending:
• ～たい です = Want to do E.g. たべます → たべたい です (Khana chahta hoon / I want to eat).
• ～たくない です = Do NOT want to do E.g. はたらきたくない です (Nahi karna chahta / Don't want to work).
• ～ましょう = Let's do! E.g. いきましょう (Chaliye chalte hain / Let's go).
• ～ませんか = Won't you do? E.g. のみませんか？ (Coffee peeyein? / Won't you drink?).

### **Grammar Point 19: ～たい です (Want to do _____)**

**ます form se ます hatao + たい です = karna chahta hoon**

| ます form | たい form | Meaning |
|---|---|---|
| たべます | たべ**たい** です | Khana chahta hoon |
| のみます | のみ**たい** です | Peena chahta hoon |
| いきます | いき**たい** です | Jaana chahta hoon |
| みます | み**たい** です | Dekhna chahta hoon |
| かいます | かい**たい** です | Khareedna chahta hoon |
| やすみます | やすみ**たい** です | Aaram karna chahta hoon |
| します | し**たい** です | Karna chahta hoon |

**Negative:** たい → たくない です

**Examples:**
- すし を たべたい です。 → Sushi khana chahta hoon.
- にほん に いきたい です。 → Japan jaana chahta hoon.
- きょう は やすみたい です。 → Aaj aaram karna chahta hoon.
- あまり はたらきたくない です。 → Zyada kaam nahi karna chahta.

**Question:**
- なに を たべたい ですか？ → Kya khana chahte ho?
- どこ に いきたい ですか？ → Kahaan jaana chahte ho?

### **Grammar Point 21: ～ましょう (Let's _____! / Chaliye _____!)**

**ます form se ます hatao + ましょう = chaliye karte hain**

| ます form | ましょう form | Meaning |
|---|---|---|
| たべます | たべましょう | Chaliye khaate hain |
| いきます | いきましょう | Chaliye chalte hain |
| のみます | のみましょう | Chaliye peete hain |
| します | しましょう | Chaliye karte hain |
| やすみます | やすみましょう | Chaliye aaram karte hain |

**Examples:**
- いっしょに (一緒に) ひるごはん を たべましょう。 → Saath mein lunch khaate hain.
- あした えいが を みましょう。 → Kal movie dekhte hain.
- カラオケ に いきましょう！ → Karaoke chalte hain!

**Response:**
- はい、いいですね！ → Haan, accha hai! (Agreement)
- はい、そう しましょう。 → Haan, aisa karte hain.
- すみません、ちょっと… → Sorry, thoda mushkil hai... (Polite refusal)

### **Grammar Point 22: ～ませんか (Won't you _____? / _____ karte hain?)**
