Grammar Point 4: これ / それ / あれ (This / That / That over there) これ (This)
これ / それ / あれ は [Item] です

• これ (kore) = Yeh (mere paas - near speaker)
• それ (sore) = Woh (tumhare paas - near listener)
• あれ (are) = Woh (dono se door - far from both)
• どれ (dore) = Kaunsa? (Which one - question)

これ は なんですか？ → それ は すし です。
Kore wa nan desu ka? → Sore wa sushi desu. (Yeh kya hai? → Woh sushi hai.)

### **Grammar Point 3: _____ を ください (Please give me _____)**

- **を (wo/o)** = Object marker particle
- **ください (kudasai)** = Please give / Please do

**Examples:**
- みず を ください。 → Paani dijiye.
- コーヒー を ください。 → Coffee dijiye.
- これ を ください。 → Yeh dijiye.

---

### **Grammar Point 4: これ / それ / あれ (This/That/That over there)**

| Japanese | Reading | Meaning | Kitni door |
|---|---|---|---|
| これ | Kore | Yeh (mere paas) | Paas |
| それ | Sore | Woh (tumhare paas) | Thoda door |
| あれ | Are | Woh (dono se door) | Bahut door |
| どれ | Dore | Kaunsa? | Question |

**Examples:**
- これ は なんですか？ (Kore wa nan desu ka?) = Yeh kya hai?
- それ は すし です。 (Sore wa sushi desu.) = Woh sushi hai.

---

### **Grammar Point 5: _____ が すきです / きらいです (Like/Dislike)**

- **が (ga)** = Subject marker particle
- **すき (好き - suki)** = Pasand
- **きらい (嫌い - kirai)** = Napasand
- **だいすき (大好き - daisuki)** = Bahut pasand

**Examples:**
- わたし は すし が すき です。 → Mujhe sushi pasand hai.
- わたし は カレー が だいすき です。 → Mujhe curry bahut pasand hai.
- にく が きらい です。 → Mujhe meat pasand nahi hai.

**Question:**
- なに が すきですか？ (Nani ga suki desu ka?) = Kya pasand hai?
