Permissions, Prohibitions & Desires てもいい / てはいけない / ほしい
て-form + も いいですか (May I?) / ては いけません (Must not!)

Master Japanese rules, manners, and house hunting requests:
• ～ても いいですか？ = Permission E.g. まど を あけても いいですか？ (Khidki khol sakta hoon? / May I open?). Answer: はい、いいですよ / どうぞ.
• ～ては いけません = Prohibition E.g. たばこ を すっては いけません (Cigarette peena mana hai / Smoking forbidden!).
• ～ないで ください = Request not to do E.g. しゃしん を とらないで ください (Photo mat lijiye / Please don't take photos).
• ～が ほしい です = Want a noun E.g. ひろい へや が ほしい です (Bada kamra chahiye / Want a spacious room). Note: use ～たい for verbs!

### **Grammar Point 28: _____ に _____ が あります/います (Describing what's in a place)**

**Structure:** [Place] に [Thing/Person] が あります/います

**Examples:**
- へや に ベッド が あります。 → Kamre mein bed hai.
- だいどころ に れいぞうこ が あります。 → Kitchen mein fridge hai.
- にわ に ねこ が います。 → Bageche mein billi hai.
- リビング に テレビ と ソファー が あります。 → Living room mein TV aur sofa hai.

**Negative:**
- へや に エアコン が ありません。 → Kamre mein AC nahi hai.

### **Grammar Point 29: _____ は _____ に あります/います (Telling location of something)**

**Structure:** [Thing/Person] は [Place] に あります/います

Yeh upar wale se ulta hai - pehle cheez batao, phir jagah:

- かぎ は テーブル の うえ に あります。 → Chaabi table ke upar hai.
- ねこ は ベッド の した に います。 → Billi bed ke neeche hai.
- リモコン は ソファー の よこ に あります。 → Remote sofa ke bagal mein hai.

### **Grammar Point 30: _____ が ほしい です (Want something)**

**ほしい (hoshii)** = Chahiye/Want (noun ke liye)

⚠️ **Difference:**
- **～たい です** = Karna chahta hoon (verb/action ke liye)
- **～が ほしい です** = Chahiye (noun/thing ke liye)

**Examples:**
- あたらしい パソコン が ほしい です。 → Naya computer chahiye.
- ひろい へや が ほしい です。 → Bada kamra chahiye.
- エアコン が ほしい です。 → AC chahiye.

**Negative:** ほしくない です (nahi chahiye)
- あまり おおきい いえ は ほしくない です。 → Zyada bada ghar nahi chahiye.

**Question:**
- なに が ほしい ですか？ → Kya chahiye?
- どんな へや が ほしい ですか？ → Kaisa kamra chahiye?

---

### **Grammar Point 31: どんな (Kaisa/Kis tarah ka)**

**どんな (donna)** = Kaisa/Kis type ka + Noun

**Examples:**
- どんな へや が いいですか？ → Kaisa kamra accha hai?
- どんな りょうり が すきですか？ → Kis tarah ka khana pasand hai?
- どんな おんがく を ききますか？ → Kaisa music sunte ho?

**Answers:**
- しずかな へや が いいです。 → Shaant kamra accha hai.
- からい りょうり が すきです。 → Teekha khana pasand hai.

### **Grammar Point 32: ～てもいいですか？ (Permission lena)**

**て-form + も いいですか？ = _____ kar sakta hoon? / _____ karna allowed hai?**

| Japanese | Meaning |
|---|---|
| ここ で しゃしん を とっても いいですか？ | Yahaan photo le sakta hoon? |
| ここ に すわっても いいですか？ | Yahaan baith sakta hoon? |
| まど を あけても いいですか？ | Khidki khol sakta hoon? |
| エアコン を つけても いいですか？ | AC chalu kar sakta hoon? |
| でんわ を つかっても いいですか？ | Phone use kar sakta hoon? |

**Answers:**
