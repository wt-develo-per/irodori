まず、おかね を いれます。つぎに、のみもの の ボタン を おします。さいごに、のみもの と おつり を とります。
Mazu, okane wo iremasu. Tsugi ni, nomimono no botan wo oshimasu. Saigo ni, nomimono to otsuri wo torimasu.
Hindi Translation: Sabse pehle, paise daalo. Uske baad, drink ka button dabao. Ant mein, drink aur chhutta (change) lo.
Sequence Connectors Grammar まず / つぎに / さいごに
まず (First) → つぎに (Next) → それから (Then) → さいごに (Finally)

When explaining a process or giving step-by-step guidance in a Japanese factory, office, or train station, use these sequence adverbs:
• まず (Mazu) = Sabse pehle / First of all.
• つぎに (次に - Tsugi ni) = Uske baad / Next step.
• それから (Sorekara) / そのあと (その後 - Sono ato) = Phir / After that.
• さいごに (最後に - Saigo ni) = Ant mein / Finally / Last step.

How-to, Conditionals & Trying New Things ～かた / ～たら / ～と / ～てみます
ます-stem + かた / た-form + ら (If/When) / Dict-form + と (Automatic result) / て-form + みます

• ～かた (Grammar Pt 44) = Karne ka tareeka / How to do. Remove ます from any verb and add かた (方)! Notice that the object particle を changes to の (e.g. きかい の つかいかた - machine use method, かんじ の よみかた - kanji reading method).
• ～たら (Grammar Pt 47) = Agar/Jab _____ ho (Conditional "If/When"). Formed by taking the past tense た form + ら (e.g. ボタン を おしたら - button dabane pe, わからなかったら - samajh na aaye toh).
• ～と (Grammar Pt 48) = Automatic natural result ("When A happens, B automatically happens"). Use Verb dictionary form + と (e.g. ボタン を おすと、でんき が つきます - when you press button, light turns on). ⚠️ Do NOT use と for requests or suggestions!
• ～てみます (Grammar Pt 49) = Karke dekhna / To try doing something to see what happens! Formed by て-form + みます (e.g. この りょうり を たべてみます - I'll try eating this dish).

🔗 Te-form Conjugation & Sequential Chaining (Grammar Pt 45)

Master connecting actions sequentially: ～て、～て、～ます = Pehle yeh karo, phir yeh karo!

Sequential Action Chaining Verb て-form + Verb て-form + Verbます
ボタン を おして、おかね を いれて、きっぷ を とります。

Instead of saying separate sentences like おかねをいれます。ボタンをおします。きっぷをとります。, Japanese speakers link verbs into one flowing sentence using the て-form! The tense of the entire sentence is decided by the VERY LAST verb!

### **Grammar Point 44: ～かた (How to do / Karne ka tareeka)**

**ます form se ます hatao + かた (方) = Karne ka tareeka**

| ます form | かた form | Meaning |
|---|---|---|
| つかいます | つかい**かた** | Use karne ka tareeka |
| たべます | たべ**かた** | Khane ka tareeka |
| かきます | かき**かた** | Likhne ka tareeka |
| よみます | よみ**かた** | Padhne ka tareeka |
| のみます | のみ**かた** | Peene ka tareeka |
| つくります | つくり**かた** | Banane ka tareeka |
| いきます | いき**かた** | Jaane ka tareeka |
| します | し**かた** | Karne ka tareeka |

**Examples:**
- この きかい (機械) の つかいかた を おしえて ください。
  → Is machine ka use karne ka tareeka bataaiye.

- この かんじ (漢字) の よみかた を おしえて ください。
  → Is kanji ko padhne ka tareeka bataaiye.

- きっぷ の かいかた (買い方) が わかりません。
  → Ticket khareedne ka tareeka nahi pata.

- この りょうり の つくりかた を おしえて ください。
  → Is dish banane ka tareeka bataaiye.

---

### **Grammar Point 45: ～て, ～て, ～ます (Sequential actions / Ek ke baad ek)**

**て-form se actions ko connect karna = Pehle yeh karo, phir yeh karo**

**Examples:**
- ボタン を おし**て**、おかね を いれ**て**、きっぷ を とります。
  → Button daba**ke**, paise daal**ke**, ticket nikalo.

- みぎ に まがっ**て**、まっすぐ いっ**て**、ひだり に あります。
  → Daayein mud**ke**, seedha jaa**ke**, baayein mein hai.

- て を あらっ**て**、エプロン を つけ**て**、りょうり を します。
  → Haath dho**ke**, apron lagaa**ke**, khana banate hain.

### **Te-form Rules (Important!):**

**Group 1 Verbs (う-verbs):**

| Ending | Change | Example | て-form |
|---|---|---|---|
| う、つ、る | って | かう → かって | Buy → Buying |
| | | まつ → まって | Wait → Waiting |
| | | かえる → かえって* | Return → Returning |
| む、ぶ、ぬ | んで | よむ → よんで | Read → Reading |
| | | あそぶ → あそんで | Play → Playing |
| | | しぬ → しんで | Die → Dying |
| く | いて | かく → かいて | Write → Writing |
| ぐ | いで | およぐ → およいで | Swim → Swimming |
| す | して | はなす → はなして | Speak → Speaking |

⚠️ Exception: いく → い**って** (NOT いいて)

**Group 2 Verbs (る-verbs):**
- る hatao + て
- たべる → たべて
- みる → みて
- おきる → おきて
- でる → でて

**Group 3 Verbs (Irregular):**
- する → して
- くる → きて

### **Grammar Point 46: まず / つぎに / さいごに (First / Next / Finally)**

| Japanese | Reading | Meaning |
|---|---|---|
| まず | Mazu | Sabse pehle / First |
| つぎに (次に) | Tsugi ni | Uske baad / Next |
| それから | Sorekara | Phir / Then |
| そのあと (その後) | Sono ato | Uske baad / After that |
| さいごに (最後に) | Saigo ni | Ant mein / Finally |

**Example - Vending Machine se juice khareedna:**
```
まず、おかね を いれます。
(Mazu, okane wo iremasu.)
Sabse pehle, paise daalo.

つぎに、のみもの の ボタン を おします。
(Tsugi ni, nomimono no botan wo oshimasu.)
Uske baad, drink ka button dabao.

さいごに、のみもの と おつり を とります。
(Saigo ni, nomimono to otsuri wo torimasu.)
Ant mein, drink aur chhutta lo.
```

### **Example - ATM ka use:**

```
まず、カード を いれて ください。
(Mazu, kaado wo irete kudasai.)

(Saigo ni, okane to kaado wo totte kudasai.)
Ant mein, paise aur card le lijiye.
```

### **Grammar Point 47: ～たら (If / When / Jab _____)**

**た form + ら = Agar/Jab _____ ho**

**Examples:**
- ボタン を おし**たら**、でんき が つきます。
  → Button daba**ne pe**, light chalu hoti hai.

- ここ を おし**たら**、きっぷ が でます。
  → Yahaan daba**ne pe**, ticket nikalta hai.

- わからなかっ**たら**、きいて ください。
  → Samajh na aa**ye toh**, pooch lijiye.

- おわっ**たら**、れんらくして ください。
  → Khatam ho jaa**ye toh**, contact kijiye.

- こまっ**たら**、わたし に そうだんして ください。
  → Mushkil ho **toh**, mujhse salah kijiye.

---

### **Grammar Point 48: ～と (If/When - automatic result)**

**Dictionary form + と = Jab _____ kare toh (automatic/natural result)**

**Examples:**
- この ボタン を おす**と**、でんき が つきます。
  → Yeh button daba**ne pe**, light chalu hoti hai.

- みぎ に まがる**と**、えき が あります。
  → Daayein mud**ne pe**, station hai.

- はる に なる**と**、さくら が さきます (咲きます)。
  → Basant aa**ne pe**, cherry blossom khilte hain.

⚠️ **と** automatic/natural result ke liye - request/suggestion ke saath nahi use karte.
