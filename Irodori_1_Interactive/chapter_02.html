Time Related Phrases & Grammar

Asking the time and explaining start and end times.

From _____ To _____ (から / まで) から (from) まで (until)
[Start Time] から [End Time] まで です

• から (kara) = se (from - start time)
• まで (made) = tak (until / to - end time)
• いま なんじ ですか？ (Ima nanji desu ka?) = Abhi kitne baje hain?

いま なんじ ですか？ → 3じ です。
Ima nanji desu ka? → Sanji desu. (Abhi kitne baje hain? → 3 baje hain.)
しごと (仕事) は 9じ から 5じ まで です。
Shigoto wa 9-ji kara 5-ji made desu. → Kaam 9 baje se 5 baje tak hai.

**AM/PM:**
- ごぜん (午前 - gozen) = AM / subah
- ごご (午後 - gogo) = PM / dopahar baad

**Example:**
- ごぜん 8じ = Subah 8 baje
- ごご 3じ 30ぷん = Dopahar 3:30 baje

### **Time Related Phrases:**

| Japanese | Reading | Meaning |
|---|---|---|
| いま なんじ ですか？ | Ima nanji desu ka? | Abhi kitne baje hain? |
| _____ じ です | _____ ji desu | _____ baje hain |
| なんじ から ですか？ | Nanji kara desu ka? | Kitne baje se hai? |
| なんじ まで ですか？ | Nanji made desu ka? | Kitne baje tak hai? |
| _____ から _____ まで | _____ kara _____ made | _____ se _____ tak |

**Example:**
- しごと (仕事 - shigoto) は 9じ から 5じ まで です。
- Kaam 9 baje se 5 baje tak hai.

### **Phone Number (でんわばんごう / Denwa Bangou):**

Phone number bolte waqt har digit alag alag bolte hain.

**Special readings in phone numbers:**
- 0 = ゼロ (zero) ya れい (rei)
- Hyphen = の (no)

**Example:**
- 090-1234-5678 = ゼロ きゅう ゼロ の いち に さん よん の ご ろく なな はち

**Phrase:**
- でんわばんごう は なんばん ですか？ = Phone number kya hai?
- (でんわばんごう は) 090-xxxx-xxxx です。
