Grammar Point 10: しゅみ は _____ です (Hobby Batana) Verb + こと (koto) Rule
しゅみ は [Noun / Verb (dict form) + こと] です

Question: しゅみ は なんですか？ (Shumi wa nan desu ka?) = Aapka hobby kya hai?

To answer, you can either use a simple noun (しゅみ は りょこう です - My hobby is travel) OR convert an action verb into a noun by adding こと (koto) after its dictionary form (like -ing in English or -na in Hindi):
• みます (watch) → みる こと (dekhna / watching) → しゅみ は えいが を みる こと です。
• ききます (listen) → きく こと (sunna / listening) → しゅみ は おんがく を きく こと です。
• たべます (eat) → たべる こと (khana / eating) → しゅみ は おいしいもの を たべる こと です。

Grammar Point 12: _____ で _____ を します (Place + Activity) で = Place of Action
[Place] で [Object] を [Verb]

で (de) marks the specific location where an action takes place (kahaan pe koi kaam karte ho):
• うち で テレビ を みます。 → Ghar pe TV dekhta hoon.
• こうえん で さんぽ を します。 → Park mein walk karta hoon.
• ジム で うんどう を します。 → Gym mein exercise karta hoon.
• レストラン で ばんごはん を たべます。 → Restaurant mein dinner khata hoon.

Grammar Point 13: _____ と _____ (_____ ke saath / and) と = Companion / With
[Person] と [Activity / Verb]

と (to) means "Ke saath (with)" or "Aur (and)":
• ともだち と えいが を みます。 → Dost ke saath movie dekhta hoon.
• かぞく と ばんごはん を たべます。 → Family ke saath dinner khata hoon.

⚠️ Critical Exception: When you do an activity ALONE (akele), you use ひとり で (hitori de) — NEVER use と (ひとり と is WRONG!).
• ひとり で べんきょう します。 → Akele padhai karta hoon.

### **Grammar Point 10: しゅみ は _____ です (Hobby batana)**

**Question:** しゅみ は なんですか？ (Shumi wa nan desu ka?) = Aapka hobby kya hai?

**Answer patterns:**

```
しゅみ は りょこう です。
(Shumi wa ryokou desu.)
Mera shauk travel hai.

しゅみ は えいが を みること です。
(Shumi wa eiga wo miru koto desu.)
Mera shauk movie dekhna hai.

しゅみ は おんがく を きくこと です。
(Shumi wa ongaku wo kiku koto desu.)
Mera shauk music sunna hai.
```

⚠️ **Verb + こと (koto)** = verb ko noun bana deta hai (like -ing in English / -na in Hindi)
- みます → みること = dekhna
- ききます → きくこと = sunna
- たべます → たべること = khana (eating)
- よみます → よむこと = padhna

**Frequency Order (zyada → kam):**
```
いつも > よく > ときどき > たまに > あまり～ません > ぜんぜん～ません
Always > Often > Sometimes > Rarely > Not much > Not at all
```

**Examples:**
- まいにち コーヒー を のみます。 → Har roz coffee peeta hoon.
- よく えいが を みます。 → Aksar movie dekhta hoon.
- ときどき りょうり を します。 → Kabhi kabhi khana banata hoon.
- あまり うんどう を しません。 → Zyada exercise nahi karta.
- ぜんぜん おさけ を のみません。 → Bilkul sharab nahi peeta.
