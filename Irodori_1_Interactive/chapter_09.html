Grammar Point 27: _____ ことが あります (Experience Batana) た Form + ことが あります
[Verb た-form / Past Plain] + ことが あります = Have done ~ (Experience)

To express a life experience ("I have visited Japan before" or "I have eaten sushi"), change the verb to its た-form (past plain form) and add ことが あります:

ます form た form (Past Plain) Experience Sentence (ことが あります) Meaning
いきます (ikimasu) いった (itta) にほん に いった ことが あります。 Japan gaya hai (I have been to Japan).
たべます (tabemasu) たべた (tabeta) すし を たべた ことが あります。 Sushi khaya hai (I have eaten sushi).
みます (mimasu) みた (mita) ふじさん を みた ことが あります。 Mt. Fuji dekha hai (I have seen Mt. Fuji).
のみます (nomimasu) のんだ (nonda) にほんしゅ を のんだ ことが あります。 Japanese sake peeyi hai (I have drunk sake).
Q: にほん に いった ことが ありますか？ (Japan gaye ho kabhi?) • はい、あります (Haan, gaya hoon) • いいえ、ありません (Nahi, kabhi nahi gaya).
Past Tense Mastery: Verbs & Adjectives ました / かった / でした
Verbs: ました / い-Adj: ～かった です / な-Adj: ～でした

In Japanese, both verbs and adjectives conjugate into the past tense! Look at the rules:
• Verbs (ます form): ます → ました E.g. みました (dekha / watched), Neg: ませんでした.
• い-Adjectives: Remove い + かった です E.g. た의しい → たのしかった です (mazedaar tha / was fun). Neg: くなかった です. ⚠️ Exception: いい (accha) → よかった です (accha tha)!
• な-Adjectives: Add でした E.g. きれい → きれい でした (sundar tha / was beautiful). Neg: じゃなかったです.

### **Grammar Point 24: _____ は どう でしたか？ (Kaisa tha?)**

**どう (dou)** = Kaisa
**どうでしたか (dou deshita ka)** = Kaisa tha?

**Examples:**
- りょこう は どう でしたか？ → Travel kaisa tha?
- えいが は どう でしたか？ → Movie kaisi thi?
- にほん の たべもの は どう でしたか？ → Japan ka khana kaisa tha?

**Answers:**

| Japanese | Reading | Meaning |
|---|---|---|
| たのしかった です (楽しかった) | Tanoshikatta desu | Mazedaar tha |
| おもしろかった です (面白かった) | Omoshirokatta desu | Interesting tha |
| よかった です | Yokatta desu | Accha tha |
| おいしかった です | Oishikatta desu | Swadisht tha |
| きれい でした | Kirei deshita | Sundar tha |
| すごかった です | Sugokatta desu | Amazing tha |
| たいへん でした (大変) | Taihen deshita | Mushkil tha |
| つまらなかった です | Tsumaranakatta desu | Boring tha |
| あまり よくなかった です | Amari yokunakatta desu | Zyada accha nahi tha |

### **Grammar Point 25: い-Adjective Past Tense**

| Form | Pattern | Example |
|---|---|---|
| Present + | たかい です | Mehenga hai |
| Present - | たかくない です | Mehenga nahi hai |
| Past + | たか**かった** です | Mehenga **tha** |
| Past - | たか**くなかった** です | Mehenga **nahi tha** |

**Rule:** い hatao + かった / くなかった

**More examples:**
- おもしろい → おもしろかった です (interesting tha)
- たのしい → たのしかった です (mazedaar tha)
- おいしい → おいしかった です (tasty tha)
- さむい (寒い) → さむかった です (thanda tha)
- あつい (暑い) → あつかった です (garam tha)

⚠️ **Exception:** いい (accha) → **よかった** です (accha tha) [NOT いかった]

---

### **Grammar Point 26: な-Adjective Past Tense**

| Form | Pattern | Example |
|---|---|---|
| Present + | しずか です | Shaant hai |
| Present - | しずか じゃないです | Shaant nahi hai |
| Past + | しずか **でした** | Shaant **tha** |
| Past - | しずか **じゃなかったです** | Shaant **nahi tha** |

**Examples:**
- きれい → きれい でした (sundar tha)
- にぎやか → にぎやか でした (bustling tha)
- たいへん → たいへん でした (mushkil tha)
- ひま (暇) → ひま でした (free tha / koi kaam nahi tha)

### **Grammar Point 27: _____ ことが あります (Experience batana)**

**Verb (た form / past plain form) + ことが あります = _____ kiya hai (experience)**

Abhi basic examples:

| ます form | た form | Example |
|---|---|---|
| たべます | たべた | すし を たべた ことが あります |
| いきます | いった | にほん に いった ことが あります |
| みます | みた | ふじさん を みた ことが あります |
| のみます | のんだ | にほんしゅ を のんだ ことが あります |

**Examples:**
- にほん に いった ことが あります。 → Japan gaya hai (experience hai).
- すし を たべた ことが あります。 → Sushi khaya hai.
- にほん に いった ことが ありません。 → Japan kabhi nahi gaya.

**Question:**
- にほん に いった ことが ありますか？ → Japan gaye ho kabhi?
  - はい、あります。 → Haan, gaya hoon.
  - いいえ、ありません。 → Nahi, kabhi nahi gaya.
