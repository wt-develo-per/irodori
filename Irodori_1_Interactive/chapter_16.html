### **Grammar Point 59: ～ましょうか (Shall I? / Main kar doon?)**

**ましょう ka question form = Offer karna**

⚠️ **Difference:**
- ～ましょう = Chaliye karte hain (Let's do together)
- ～ましょうか？ = Main kar doon? (Shall I do it for you?)

**Examples:**
- てつだい**ましょうか**？ → Main madad kar doon?
- まど を あけ**ましょうか**？ → Khidki khol doon?
- しゃしん を とり**ましょうか**？ → Photo le doon?
- おしえ**ましょうか**？ → Bataa doon?
- もって いき**ましょうか**？ → Lekar jaun?

**Response:**
- はい、おねがいします。 → Haan, please.
- いいえ、だいじょうぶ です。 → Nahi, theek hai.

### **Grammar Point 61: ～う/よう (Let's - casual form of ましょう)**

| Polite | Casual | Meaning |
|---|---|---|
| たべましょう | たべよう | Chaliye khaate hain |
| いきましょう | いこう | Chaliye chalte hain |
| のみましょう | のもう | Chaliye peete hain |
| しましょう | しよう | Chaliye karte hain |
| みましょう | みよう | Chaliye dekhte hain |
| あそびましょう | あそぼう | Chaliye khelten hain |

**Rule:**
- **Group 1 (う-verbs):** Last う sound → おう sound
  - いく → いこう
  - のむ → のもう
  - あそぶ → あそぼう
  - はなす → はなそう
- **Group 2 (る-verbs):** る hatao + よう
  - たべる → たべよう
  - みる → みよう
- **Irregular:**
  - する → しよう
  - くる → こよう

### **Grammar Point 62: ～ない？ (Won't you? - Casual invitation)**

**ない form を question = Casual invitation**

**Examples:**
- いっしょに いか**ない**？ → Saath chalega?
- こんど のま**ない**？ → Agle baar peeyein?
- あした あそば**ない**？ → Kal khelein/ghumein?
- えいが み**ない**？ → Movie dekhega?

**Response:**
- いいね！ → Accha hai! (Haan)
- いいよ！ → Theek hai! (Haan)
- うん、いこう！ → Haan, chalte hain!
- ごめん、ちょっと... → Sorry, thoda mushkil hai...
- その ひ は ちょっと つごう が わるい... → Us din thoda schedule kharab hai...

### **Grammar Point 63: ～し、～し (Listing reasons)**

**Plain form + し、Plain form + し = _____ bhi hai aur _____ bhi hai (isliye)**

Multiple reasons dene ke liye:

**Examples:**
- あの レストラン は おいしい **し**、やすい **し**、よく いく。
  → Woh restaurant tasty bhi hai, sasta bhi hai, isliye aksar jaata hoon.

- きょう は あたま が いたい **し**、ねつ も ある **し**、やすみたい。
  → Aaj sir dard bhi hai, bukhar bhi hai, isliye aaram karna chahta hoon.

- にほん は たべもの が おいしい **し**、ひと が やさしい (優しい) **し**、すき です。
  → Japan mein khana tasty bhi hai, log acche bhi hain, isliye pasand hai.

### **Grammar Point 64: ～んです / ～のです (Explanation / Reason dena)**

**Plain form + んです = Actually _____ hai (explaining)**

Yeh tab use hota hai jab kisi cheez ka reason ya background explain kar rahe ho:

**Examples:**
- どうしたんですか？ → Kya hua? (What happened - asking for explanation)

- あたま が いたい **んです**。 → Actually sir dard hai.

- あした にほん に いく **んです**。 → Actually kal Japan ja raha hoon.

- どうして やすんだんですか？ → Kyun chutti li? (Why did you take leave?)
  - ねつ が あった **んです**。 → Actually bukhar tha.

**Casual:** ～んだ / ～の
- あした いく**んだ**。 → Actually kal ja raha hoon.
- なに してる**の**？ → Kya kar rahi ho? (soft question)
