Grammar Point 16 & 17: あります vs います Critical Difference!
[Item/Person] は [Landmark] の [Position] に [あります/います]

In Japanese, existence verbs change depending on whether the subject is living or non-living:

🏢 あります / ありません (Non-Living)

Used for inanimate objects, buildings, plants, vehicles, and abstract things.
• ここ に コンビニ が あります (Here is a convenience store).
• ATM は ありません (There is no ATM).
• この まち に びょういん が あります (This town has a hospital).

🐱 います / いません (Living Things)

Used for humans, animals, birds, and insects (things that move on their own).
• ここ に ねこ が います (Here is a cat).
• だれ も いません (There is nobody here).
• こうえん に こども が います (There are children in the park).

### **Grammar Point 15: _____ は どこ ですか？ (Kahaan hai?)**

**どこ (doko)** = Kahaan

**Examples:**
- トイレ は どこ ですか？ → Toilet kahaan hai?
- えき は どこ ですか？ → Station kahaan hai?
- ぎんこう は どこ ですか？ → Bank kahaan hai?

---

### **Grammar Point 16: Location description - _____ の _____ に あります/います**

**あります (arimasu)** = Hai (non-living things ke liye)
**います (imasu)** = Hai (living things ke liye - logon/jaanwaron ke liye)

**Structure:** [Reference Point] の [Direction] に あります/います

**Examples:**
- ぎんこう は えき の まえ に あります。
  → Bank station ke saamne hai.

- コンビニ は びょういん の となり に あります。
  → Convenience store hospital ke bagal mein hai.

- ゆうびんきょく は ぎんこう と スーパー の あいだ に あります。
  → Post office bank aur supermarket ke beech mein hai.

- ねこ (猫) は テーブル の した に います。
  → Billi table ke neeche hai.

---

### **Grammar Point 17: あります vs います**

| Verb | Reading | Use | Example |
|---|---|---|---|
| あります | Arimasu | Non-living (cheezein, buildings) | ここ に コンビニ が **あります** |
| います | Imasu | Living (log, jaanwar) | ここ に ねこ が **います** |
| ありません | Arimasen | Non-living - nahi hai | ATM は ありません |
| いません | Imasen | Living - nahi hai | だれ も いません (koi nahi hai) |

**Example:**
- この まち に びょういん が あります。 → Is sheher mein hospital hai.
- こうえん に こども (子供) が います。 → Park mein bacche hain.

### **Grammar Point 18: ～て ください (Please do _____)**

**て-form (te-form)** + ください = Please do ~

Yeh bahut important form hai! Abhi basic te-forms:

| ます form | て form | Meaning |
|---|---|---|
| いきます | いって | Jaana |
| まがります | まがって | Mudna |
| わたります (渡ります) | わたって | Paar karna |
| のります (乗ります) | のって | Sawaar hona |
| おります (降ります) | おりて | Utarna |
| みます | みて | Dekhna |
| まちます (待ちます) | まって | Intezaar karna |

**Examples:**
- まっすぐ いって ください。 → Seedha jaiye.
- ここ で まって ください。 → Yahaan intezaar kijiye.
- 3ばん の バス に のって ください。 → Number 3 ki bus mein baithiye.
- つぎ の えき で おりて ください。 → Agle station pe utriye.
